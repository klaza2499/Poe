# Exile-UI ภาษาไทย 🇹🇭

แพ็กภาษาไทยสำหรับ [Exile-UI](https://github.com/Lailloken/Exile-UI) (เดิมชื่อ Lailloken UI) — แปลเมนู ปุ่ม ข้อความแจ้งเตือน และหน้าตั้งค่า

## ติดตั้ง

1. ปิด Exile-UI ก่อน
2. **ลากโฟลเดอร์ Exile-UI** (โฟลเดอร์ที่มีไฟล์ `Exile UI.ahk`) มาวางบน **`install.bat`**
   — หรือดับเบิลคลิก `install.bat` แล้วลากโฟลเดอร์มาวางในหน้าต่างแล้วกด Enter
3. เปิด Exile-UI ใหม่ → เป็นภาษาไทยแล้ว (เปลี่ยนภาษาได้ที่ ตั้งค่า → ทั่วไป → ภาษา)

ต้องมี Python 3 (ตัวเดียวกับที่ใช้รัน PoE Act Helper)

**กลับเป็นอังกฤษ:** ลากโฟลเดอร์ Exile-UI มาวางบน `undo.bat`

## สิ่งที่สคริปต์ทำ

- สร้าง `data/thai/UI.txt` จาก `data/english/UI.txt` **ของเครื่องคุณ** — จึงตรงกับเวอร์ชันที่ใช้อยู่เสมอ
  ข้อความใหม่ที่ยังไม่มีคำแปลจะแสดงเป็นอังกฤษ (Exile-UI รองรับแบบนี้อยู่แล้ว)
- เปลี่ยนฟอนต์เป็น **Leelawadee UI** (ฟอนต์ Fontin เดิมไม่มีอักษรไทย) — สำรองไฟล์เดิมไว้เป็น `client.txt.bak`
- ตั้ง `language=thai` ใน `ini/config.ini`

## หมายเหตุ

- **ชื่อในเกมคงเป็นภาษาอังกฤษ** (ไอเท็ม, ลีก, NPC, Sanctum, Betrayal ฯลฯ) ให้ตรงกับที่เห็นในเกมภาษาอังกฤษ
- **ไกด์ Act-Tracker ยังเป็นภาษาอังกฤษ** — คำสั่งพิเศษในไกด์ (`kill`, `optional:`, `leaguestart:` …) ถูกล็อกไว้ไม่แปล
  เพราะ Exile-UI ใช้คำเหล่านี้อ่านไกด์ ถ้าแปลไกด์จะแสดงผิด
  (อยากได้ไกด์ภาษาไทยใช้ **PoE Act Helper** ในโฟลเดอร์หลักของ repo นี้)
- คำอธิบายเมื่อชี้เมาส์ (help tooltips) ยังเป็นภาษาอังกฤษ
- **อัปเดต Exile-UI แล้วต้องรัน `install.bat` ใหม่** เพราะตัวอัปเดตอาจเขียนทับฟอนต์และไม่รู้จักคำแปลใหม่
- แก้/เพิ่มคำแปลได้ที่ [`translations.py`](translations.py) (จับคู่ด้วยข้อความภาษาอังกฤษ)
