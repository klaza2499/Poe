# ภาพ layout แมพ

วางภาพ (png / gif / jpg*) ไว้ในโฟลเดอร์นี้ โปรแกรมจะแสดงภาพของโซนปัจจุบันให้อัตโนมัติ (กด 🗺 หรือ Ctrl+Alt+M)

ตั้งชื่อได้ 3 แบบ:

| แบบ | ตัวอย่าง |
|---|---|
| ไฟล์ขึ้นต้นด้วยรหัสโซน | `1_1_3.png`, `1_1_3_แบบ2.png` |
| โฟลเดอร์ชื่อรหัสโซน | `1_1_3/อะไรก็ได้.png` |
| โฟลเดอร์ชื่อโซน + Act | `The Mud Flats (Act 1)/a.png` |

รหัสโซนดูได้จากช่อง `area` ใน `poe_act_helper/data/route_poe1.json` หรือจากข้อความในหน้าต่าง layout

ภาพที่แคปด้วย 📷 / Ctrl+Alt+S จะถูกเก็บที่ `%USERPROFILE%\.poe_act_helper\layouts\<รหัสโซน>\`

\* jpg และการแคปหน้าจอต้องติดตั้ง Pillow: `pip install pillow`
